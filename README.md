# Roza Belay – Portfolio

Personal portfolio website built with React, TypeScript, Vite and TanStack Start.

## Tech Stack

- React 19
- TypeScript
- Vite
- TanStack Start
- Tailwind CSS
- Radix UI

## Development

Install dependencies:

npm install

Start development server:

npm run dev

Build for production:

npm run build

Run tests:

npm test

## Deployment

Deployed through Netlify and connected to GitHub.X
