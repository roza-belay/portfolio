Installation

Clone the repository:

bash
git clone <your-github-repository-url>
cd <your-repository-name>


Install dependencies:

bash
npm install


Start the development server:

bash
npm run dev


Open the local URL displayed in your terminal.

Build

Create a production build:

bash
npm run build
