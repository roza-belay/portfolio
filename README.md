# Roza Belay Portfolio

A dark violet React + TypeScript portfolio for Roza Belay, fullstack developer with frontend focus.

## Highlights

- React + TypeScript + Vite
- CV-driven content in Swedish
- Project sections for POS PSDK integration, React chat app, and webshop/fullstack work
- Responsive dark violet design
- Contact links for email, phone, LinkedIn, and GitHub

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
